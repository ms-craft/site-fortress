## О проекте

Веб-сайт создан в рамках образовательного проекта и представляет собой интерактивный путеводитель по Брестской крепости — одной из самых известных крепостей мира, ставшей символом мужества и стойкости в годы Великой Отечественной войны.

## Разделы сайта

| Раздел | Описание |
|--------|----------|
| **[Главная](index.html)** | Интерактивная карта с отмеченными объектами крепости |
| **[История крепости](history.html)** | Хронология событий от основания до наших дней |
| **[Фортификационные сооружения](forts.html)** | Форты, казармы, пороховые погреба и батареи |
| **[Защитники крепости](defenders.html)** | Герои обороны 1941 года |
| **[Градостроительство](cites.html)** | Архитектурное развитие территории крепости |
| **[Экскурсии](excursions.html)** | Маршруты и информация для посетителей |
| **[Библиография](sources.html)** | Источники и литература |

## Возможности

- **Интерактивная карта** — Яндекс.Карты с цветовыми метками по категориям объектов
- **Модальные окна** — подробная информация об объектах при клике на метку
- **Адаптивное меню** — два состояния: компактное (десктоп) и полноэкранное (мобильные устройства)
- **Sticky-навигация** — компактная панель при прокрутке на десктопе, sticky-хедер на мобильных
- **Анимации** — плавные переходы меню, кнопок и модальных окон
- **Полная адаптивность** — корректное отображение на всех размерах экрана

## Технологии

```
├── HTML5          — семантическая разметка
├── CSS3           — кастомные свойства, flexbox, grid, анимации
│   ├── style.css       — базовые стили компонентов
│   └── adaptive.css    — медиа-запросы и адаптивная вёрстка
├── JavaScript     — vanilla JS, без фреймворков
│   ├── app.js              — основная логика (меню, модалки, скролл)
│   ├── defenders-modal.js  — модальные окна страницы защитников
│   └── map.js              — интеграция Яндекс.Карт
├── Yandex Maps API — интерактивная карта
└── Google Fonts    — шрифты Rubik Mono One, Bellota Text, Oswald, Ubuntu Condensed
```

## Запуск

Проект состоит из статических файлов и не требует сборки:

```bash
git clone https://github.com/username/geoUpdate.git
cd geoUpdate
# открыть index.html в браузере
```

> **Примечание:** для работы интерактивной карты необходим подключение к интернету (Yandex Maps API).
