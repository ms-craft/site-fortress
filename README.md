## 🏰 О проекте

**Брестская фортеция** — это полностью адаптивный веб-сайт, посвященный истории фортификационных сооружений, их защитникам и экскурсионным маршрутам. Проект разработан с использованием современных стандартов семантической верстки и обеспечивает корректное отображение на любых устройствах: от мобильных телефонов до широкоформатных мониторов.

### ✨ Ключевые особенности
* 📱 **Полная адаптивность:** интерфейс гибко подстраивается под любые экраны благодаря `adaptive.css`.
* 🗺️ **Интерактивная карта:** Удобная интерактивная карата сделанная при помощи `yandexApi` и сгенерированного json файла из csv `points.json` для вывода объектов.
* 📚 **Информативность:** раздельные тематические страницы для глубокого погружения в историю фортов.

## 🛠️ Техническая часть

Проект построен на базе классических фронтенд-технологий без использования фреймворков:

| Технология | Назначение |
| :--- | :--- |
| HTML5 | Семантическая структура страниц (`index.html`, `forts.html`) |
| CSS3 | Стилизация и адаптивная сетка (`css/`, `adaptive.css`) |
| JavaScript | Логика взаимодействия и обработка данных (`js/`) |
| JSON | Хранение координатных точек и информации для модальных окон (`points.json`) |

---

## 📂 Структура проекта

* `index.html` — Главная страница проекта.
* `forts.html` — Каталог фортов и оборонительных сооружений.
* `defenders.html` — Страница, посвященная защитникам Брестской крепости.
* `excursions.html` — Информация о доступных экскурсиях и маршрутах.
* `history.html` — Историческая справка о Брестской крепости.
* `sources.html` — Список используемых источников и литературы.
